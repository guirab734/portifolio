# Imagens dos projetos

As capas usam capturas reais quando há uma interface acessível e ilustrações
conceituais nos demais casos. Ilustrações não representam capturas de tela e são
identificadas nos cards em português e inglês.

| Projeto | Origem da imagem |
| --- | --- |
| Guirab Placas | Captura da demonstração com dados fictícios |
| Recursos da Tia Cris | Captura do site público |
| Ritmo | Captura da demonstração com dados fictícios |
| Radar de Impacto | Ilustração conceitual gerada para representar sensores e localização |
| Cantinho Pedidos | Ilustração conceitual gerada para representar salão e cozinha |
| Estoque de Hardware | Captura do frontend local original com dados de exemplo |
| Provisionamento de Unidades | Ilustração conceitual gerada para representar CSV e validação de endereços |
| GGAMES | Ilustração conceitual gerada para representar locação de equipamentos |
| Jovem Tech | Captura da interface do projeto local |
| Velora | Captura da página pública publicada na Vercel |
| Brownies da Soso | Captura da interface do projeto local |

As imagens são distribuídas localmente em WebP, sem depender de imagens do Google
ou de links externos para a carga dos cards. As capturas de Estoque usam dois
produtos fictícios; não consultam um banco de produção.

## Ritmo

A ilustração da puxada frontal foi substituída por uma versão com o rosto à frente
e a cabeça alinhada ao tronco nas duas posições. O arquivo independente fica em
`public/demos/ritmo/assets/puxada-frontal-v2.webp`. A ficha usa esse arquivo em vez
do recorte antigo da folha. O importador preserva a substituição.

## Código privado

Os links dos repositórios próprios privados foram retirados dos cards. Projetos
em equipe mantêm seus links de origem, pertencentes a outras pessoas. Os sites e
demonstrações publicados continuam acessíveis sem acesso ao código-fonte.
